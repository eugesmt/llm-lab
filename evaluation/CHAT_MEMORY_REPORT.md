# Приёмочный отчёт: мини-чат с RAG и памятью задачи

## Что проверяется

Тесты проверяют orchestration мини-чата без обращения к реальным LLM, Ollama,
OpenRouter или внешним API. Вместо модели используется детерминированный
`RecordingRAGService`, который на каждый запрос возвращает один источник и одну
цитату.

Проверяются два независимых диалога по 12 пользовательских сообщений:

1. настройка входящих SIP-звонков;
2. локальное развёртывание LiveKit Server.

Полные реплики и ожидаемое итоговое состояние находятся в
`evaluation/chat_memory_scenarios.json`. Файл не содержит сгенерированных
ответов модели.

## Критерии приёмки

- в каждом диалоге сохраняются 12 пользовательских и 12 assistant-сообщений;
- каждый ход передаёт в сервис `conversation_context` и `retrieval_query`;
- местоименные и короткие follow-up должны расширяться целью, ограничениями или предыдущим вопросом пользователя;
- итоговый `TaskState` содержит цель, все три ограничения и зафиксированный термин;
- каждый сохранённый assistant response содержит непустые `rag_sources` и `citations`;
- второй диалог не видит историю и память первого;
- после пересоздания приложения на той же SQLite доступны история и `TaskState`;
- GET `/api/conversations/{id}` возвращает все 24 сообщения сценария, достаточные для восстановления диалога на 10–15 ходов.

## Команды запуска

Из корня `llm-lab`:

```bash
uv run pytest tests/test_long_chat_scenarios.py -q
uv run ruff check tests/test_long_chat_scenarios.py
```

Тест использует временную SQLite-базу pytest. Рабочая база приложения и
реальные провайдеры не используются.

## Результат приёмочного прогона

Прогон выполнен после двух исправлений:

- GET `/api/conversations/{id}` теперь возвращает до 200 сообщений, поэтому
  полный сценарий из 24 сообщений восстанавливается через API;
- query rewrite обрабатывает короткие follow-up, включая `А что с Redis?` и
  `И что дальше?`.

Результат:

```text
3 passed
```

Все приёмочные критерии пройдены для обоих сценариев. Реальные LLM/Ollama/API
не вызывались; ответы, источники и цитаты предоставлял детерминированный
recording service double.

В интерфейсе `enhanced` установлен режимом RAG по умолчанию. Это относится к
UI и не меняет детерминированную методику данного теста.
